# Аналоговые часы на SFML

![C++](https://img.shields.io/badge/C%2B%2B-14-00599C?logo=cplusplus)
![SFML](https://img.shields.io/badge/SFML-2.6.x-8CC445)

Учебное приложение, которое отображает текущее локальное время одновременно
в цифровом и аналоговом виде. Положение стрелок рассчитывается по системным
часам, а циферблат полностью рисуется средствами SFML.

## Что показывает пример

- получение локального времени через функции Windows CRT;
- отрисовку окружностей, прямоугольников и текста;
- размещение отметок и чисел на окружности с помощью `sin` и `cos`;
- плавное смещение минутной и часовой стрелок;
- выделение работы со временем в класс `SFMLWorldTime`.

## Структура

- `main.cpp` — окно, циферблат и три стрелки;
- `SFMLWorldTime.*` — чтение системного времени и цифровые часы;
- `Image` — иконка приложения;
- `lib` — шрифты циферблата.

## Требования

- Windows и Visual Studio 2022 либо другой совместимый компилятор;
- CMake 3.21+;
- Git и подключение к интернету при первой CMake-конфигурации.

## Сборка через CMake

SFML 2.6.x загружается автоматически с помощью `FetchContent`.

```powershell
cmake -S . -B build -DBUILD_SHARED_LIBS=OFF
cmake --build build --config Release
./build/Release/Clock.exe
```

Каталоги `Image` и `lib` автоматически копируются рядом с программой.

## Сборка готового решения

Откройте `Часы.sln`, выберите **x64** и обновите пути к SFML в свойствах
проекта, если библиотека установлена не в каталоге, записанном в `.vcxproj`.

## Управление

Приложение не требует управления. Закройте окно стандартной кнопкой **×**.

## Статус

Завершённый учебный пример. Его можно развить, добавив будильник, выбор
часового пояса, масштабирование и несколько тем оформления.
